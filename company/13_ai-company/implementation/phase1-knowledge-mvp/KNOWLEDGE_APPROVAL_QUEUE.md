# KNOWLEDGE_APPROVAL_QUEUE — 正典昇格・改版・開示の承認キュー

版: v1.0 / 2026-07-09。**オーナーが読む唯一の場所**。承認・差戻しは本ファイルへの追記のみを正とする。

---

## 運用規則

1. AI は各項目を下の書式で登録する。オーナーは「判定」欄に `承認` / `差戻し（理由）` を追記する
2. 承認済み差分は Knowledge AI が対象ファイルへ反映し、「反映済み」を本キューに追記する
3. SLA: 登録から 48 時間。超過は AI が督促 1 回 → 日次報告の警告欄へ
4. 承認された差分の反映時改変を禁止する（誤字でも再承認）。差戻しは理由を記録し、同種 2 回で分類基準・抽出手順の改版候補を起票
5. 処理済み項目は週次で本ファイル末尾の「処理済み」節へ移動する（削除しない）

---

## 対象種別

| 種別 | 説明 |
|---|---|
| 正典昇格 | 収穫素材を canon/ へ昇格させる |
| 文書改版 | Playbook / 監査キット / Skills / テンプレ / FAQ の改版 |
| 開示判定 | confidential/ から公開区画（assets/）への移動 |
| 退役 | assets / canon から archive/ への移動 |
| 棄却 | アイテムの処理終了（COMPLETED・記録必須） |
| 重複統合 | 同一の問いに答える資産の統合（どちらを正とするか） |

## 項目書式

```
### [AQ-KN-連番] 件名
- アイテムID: KN-YYYYMMDD-NNN
- 種別: 正典昇格 / 文書改版 / 開示判定 / 退役 / 棄却 / 重複統合
- 差分全文:（改版の場合: 変更前 → 変更後を全文で提示）
- 三点セット:
  - 事実:（元記録の原文・根拠件数）
  - 選択肢:（採用 / 修正採用 / 棄却）
  - 推奨と理由:
- 確信度: __%（根拠 1 行）
- 登録日時 / 期限:
- 判定:（オーナー記入）
- 反映済み:（Knowledge AI 記入）
```
