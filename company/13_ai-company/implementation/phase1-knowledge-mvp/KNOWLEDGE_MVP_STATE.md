# KNOWLEDGE_MVP_STATE — 知識アイテム台帳（唯一の正）

版: v1.0 / 2026-07-09。会社共通 8 状態のみを使用（新状態の追加禁止）。更新は必ず LOG 追記の後に行う。

---

## 記帳書式（1 アイテム = 1 行・上が最新）

```
| アイテムID | 種別 | 区画 | 状態 | 原文所在 | 確信度 | 期限 | 温度 | 最終更新 |
```

- **アイテムID**: `KN-YYYYMMDD-連番`（受領日）
- **種別**: 成功要因 / 失敗要因 / 顧客の言葉 / FAQ候補 / 部品 / 記入例 / 矛盾 / 機密
- **区画**: assets / memo / confidential / canon / archive
- **状態**: NEW / ANALYZING / READY / WAITING_APPROVAL / EXECUTING / WAITING / LEARNING / COMPLETED
- **原文所在**: ハンドオフ元 AI と LOG エントリ ID（例: Sales AI / SL-20260709-001）
- **温度**: 正常 / 注意 / 警告（警告はブリーフ即掲載）
- **期限**: WAITING 状態の確認期限（7 日）/ WAITING_APPROVAL の承認期限（48 時間）

## 状態の知識固有の意味

| 状態 | Knowledge AI での意味 |
|---|---|
| NEW | 受領済み・未分類 |
| ANALYZING | 分類・抽出・突き合わせ中（KN-MVP-03） |
| READY | 昇格案・改版案・索引が完成し提出可能 |
| WAITING_APPROVAL | 正典昇格・文書改版・開示判定の承認待ち（48 時間 SLA） |
| EXECUTING | 承認済み反映の実施・索引付け・格納 |
| WAITING | 原本提供者への確認待ち（期限 7 日） |
| LEARNING | 反映結果の記録・参照通知の発行 |
| COMPLETED | アイテムの処理完了（正典化 / メモ保存 / 棄却記録を含む） |

**規則:** 状態のない知識アイテムを禁ずる。「棄却」も記録を伴う COMPLETED であり、無言の消失を禁ずる。

## 滞留・SLA 監視

| 状態 | SLA | 超過時のアクション |
|---|---|---|
| WAITING_APPROVAL | 48 時間 | 督促 1 回 → 日次報告の警告欄へ |
| WAITING（確認待ち） | 7 日 | 期限切れは [仮定] ラベル付きメモとして保存（正典昇格の対象外） |
| ANALYZING | 2 営業日 | 週次 KPI で警告 |
