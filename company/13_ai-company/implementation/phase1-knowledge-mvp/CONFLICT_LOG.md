# CONFLICT_LOG — 仕様矛盾・未定義ログ

| 項目 | 内容 |
|---|---|
| 目的 | 文書間・記録間・指示間の矛盾・未定義状況を発見した者（人間・AI）が記録する |
| 準拠 | `PHOSARA_AI_KNOWLEDGE_RUNTIME_v1.md` §15.3: 「実装で判明した欠陥はコードで回避せず Conflict Log へ（仕様が正典、実装は写像）」 |
| 原則 | 追記のみ。矛盾を発見したときに**裁定せずに**記録する。コードで回避しない |
| 手続き | 1. 両方の記述を原文のまま併記 → 2. 上位文書を暫定適用して作業を止めない → 3. 週次レビューで人間が裁定 → 4. 下位文書へ最小修正 → 5. 裁定結果を本ログに追記して閉じる |

## 記録ルール

1. **コードで回避しない** — 矛盾をコードで吸収せず、このファイルに記録する
2. **暫定は上位文書を適用** — AI_COMPANY_OS > Agent定義 > Runtime > 本MVP文書
3. **解決前は作業継続可能な場合のみ継続** — P0（有償案件の停止・信頼毀損・障害）は即時停止してオーナー直行
4. **週次レビューで必ず提示** — 未処理のエントリは毎週金曜の週次レビューに提示する
5. **Knowledge AI の特則:** 本ログへの記帳者が自分自身（Knowledge AI）であることに最も厳格でなければならない（Runtime §14）
