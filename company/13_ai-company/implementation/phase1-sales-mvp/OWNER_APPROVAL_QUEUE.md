# OWNER_APPROVAL_QUEUE.md — オーナー承認キュー

| 項目 | 内容 |
|---|---|
| 目的 | Sales AI が生成した営業文をオーナーが確認・承認・差戻しするための台帳 |
| 書き込み者 | Claude Code（Sales AI MVP — Step 9） |
| 承認者 | オーナー（PHOSARA HQ） |
| 原則 | 追記のみ。上書き・削除禁止。承認なき送信は絶対に禁止 |

---

## オーナーへの使い方ガイド

1. このファイルを上から順に読む
2. **ステータスが `⏳ 承認待ち`** のエントリを確認する
3. 営業文（案A・案B）と三点セットを読む
4. 「**オーナーの承認欄**」に以下のいずれかを追記する：
   - `承認: 案A` または `承認: 案B`
   - `差戻し: （理由を1〜2文で記入）`
5. Claude Code に「承認キューを確認して」と伝える

---

## エントリIDの命名規則

```
AQ-YYYYMMDD-NNN
例: AQ-20260709-001（2026年7月9日 1件目）
```

---

## キューステータス一覧

| ステータス | 意味 |
|---|---|
| ⏳ 承認待ち | オーナーの判断を待っている |
| ✅ 承認済み | 承認が確認された（Phase 2接続後に送信する） |
| 🔄 差戻し | 差戻しを受けた。NEWに戻って再実行する |
| ⚠️ 期限超過 | 48時間以上承認が得られていない |

## 禁止事項

- 承認キューに登録されていない営業文の送信
- 承認された文面の一字一句の変更（誤字修正であっても再承認必須）
- エントリの上書き・削除
- 期限超過したエントリの無承認処理
