# DAILY_CLIENT_SUCCESS_REPORT — 日次報告テンプレート

版: v1.0 / 2026-07-04。共通7要素+CS固有欄。**欠落は欠落と明示する(埋めて取り繕わない)。**

```
# Daily Client Success Report — YYYY-MM-DD

## 1. 結論(3行以内)
(事実)
(推奨)

## 2. 証拠
- STATE該当行 / LOG該当区間への参照

## 3. 優先度
- 本日の最重要: P_(判定理由1行)

## 4. リスクと可逆性
- 最大リスク1つ / Type 1相当の判断待ちの有無

## 5. 次の一手
- (最小の一手・担当・期限)

## 6. PBOS資産候補
- (再利用部品。なければ「なし」)

## 7. やらないこと
- (意図的に範囲外にした事項)

## 固有欄
- 顧客ごとの温度: 正常__件 / 注意__件 / 警告__件(警告は顧客名と滞留日数)
- 約束の履行状況: 期限内__件 / 遅延__件(遅延は内容)
- 承認キュー: 未処理__件(48h超過__件)
- 明日の予約・リマインド予定: (一覧)
- 紹介の芽: (あれば1行)
```
