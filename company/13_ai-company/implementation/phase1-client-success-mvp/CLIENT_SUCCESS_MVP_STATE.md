# CLIENT_SUCCESS_MVP_STATE — 状態台帳(唯一の正)

版: v1.0 / 2026-07-04。会社共通8状態のみを使用(新状態の追加禁止)。更新は必ずLOG追記の後に行う。

## 記帳書式(1顧客=1行・上が最新)

```
| 顧客ID | 顧客名 | 状態 | 予約日時 | 次アクション | 期限 | 温度 | 最終更新 |
```

- 顧客ID: CS-YYYYMMDD-連番(ハンドオフ受領日)
- 状態: NEW / ANALYZING / READY / WAITING_APPROVAL / EXECUTING / WAITING / LEARNING / COMPLETED
- 温度: 正常 / 注意 / 警告(警告はブリーフ即掲載)
- 期限切れのWAITINGは朝バッチで検出し、確認1回→育成返送起案の順で処理する
