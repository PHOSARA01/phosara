# OWNER_APPROVAL_QUEUE — オーナー承認キュー

版: v1.0 / 2026-07-04。**オーナーが読む唯一の場所**(Sales AI MVPと同一書式・同一ファイル運用に統合可)。承認・差戻しは本ファイルへの追記のみを正とする。

## 運用規則

1. AIは各項目を下の書式で登録する。オーナーは「判定」欄に `承認` / `差戻し(理由)` を追記する
2. 承認済み文面はオーナーが手動送信し、`送信済み YYYY-MM-DD HH:MM` を追記する
3. SLA: 登録から48時間。超過はAIが督促1回→日次報告の警告欄へ
4. 承認された文面の改変禁止。修正が必要なら差戻し→再起案→再登録
5. 処理済み項目は週次で本ファイル末尾の「処理済み」節へ移動する(削除しない)

## 項目書式

```
### [CS-Q-連番] 件名
- 顧客: (顧客ID・顧客名)
- 種別: 事前案内 / リマインド / 例外相談 / 育成返送
- 三点セット:
  - 事実:
  - 選択肢:
  - 推奨と理由:
- 確信度: __%(根拠1行)
- 文面全文: (以下に全文)
- 登録日時 / 期限:
- 判定: (オーナー記入)
- 送信済み: (オーナー記入)
```
