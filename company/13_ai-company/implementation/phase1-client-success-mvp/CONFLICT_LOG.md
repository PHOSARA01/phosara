# CONFLICT_LOG — 矛盾記録

版: v1.0 / 2026-07-04。文書間・記録間・指示間の矛盾を発見した者(人間・AI)は、**裁定せずに**ここへ記録する。

## 手続き(上位正典の継承)

1. 両方の記述を**原文のまま**併記する(要約で比べない)
2. 上位文書を暫定適用して作業を止めない(優先順位: 会社OS > Agent定義 > Runtime > 本MVP文書)
3. 週次レビューで人間が裁定し、下位文書へ最小修正を加える
4. 裁定結果を本ログに追記して閉じる(蓄積知識を破棄しない・廃止記述はarchiveへ)

## 記帳書式

```
### [CFL-連番] 件名
- 発見日 / 発見者:
- 記述A(文書名・原文):
- 記述B(文書名・原文):
- 暫定適用: (上位文書とその根拠)
- 裁定: (週次レビュー記入)
- 反映: (改版したファイルと版)
```
