# DAILY_PBOS_REPORT — 日次報告テンプレート

版: v1.0 / 2026-07-04。共通7要素+PBOS固有欄。**欠落は欠落と明示する(「計測不能」をゼロと表示しない)。**

```
# Daily PBOS Report — YYYY-MM-DD

## 1. 結論(3行以内)
(事実)
(推奨)

## 2. 証拠
- STATE該当行 / LOG該当区間への参照

## 3. 優先度
- 本日の最重要: P_(判定理由1行)

## 4. リスクと可逆性
- 最大リスク1つ / Kill・Archive提案の有無

## 5. 次の一手
- (最小の一手・担当・期限)

## 6. PBOS資産候補
- (当日の資産価値台帳への記帳。なければ「なし」)

## 7. やらないこと
- (意図的に範囲外にした事項)

## 固有欄
- 受領→評価: 受領__件 / 評価済__件 / 見送り__件(理由の類型)
- 提案の状態: 起案__件 / 承認待ち__件(48h超過__件) / 採用__件 / 保留棚__件(同一工程観測中)
- 採点分布: 35+__件 / 25–34__件 / 24以下__件
- 回収周回の予実: (採用済み改善の状況。計測不能は「計測不能」と明示)
- 週次「次に変える一つ」候補: (金曜のみ・筆頭1件)
```
