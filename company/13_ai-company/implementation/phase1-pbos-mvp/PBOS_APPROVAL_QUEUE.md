# PBOS_APPROVAL_QUEUE — オーナー承認キュー

版: v1.0 / 2026-07-04。既存MVPと同一書式(Phase 2で全Runtime共通キューに統合)。承認・縮小採用・見送りは本ファイルへの追記のみを正とする。

## 運用規則

1. AIは各項目を下の書式で登録する。オーナーは「判定」欄に `採用` / `縮小採用(範囲)` / `見送り(理由)` を追記する
2. 承認対象: 改善提案 / Kill・Archive提案 / 保留棚からの再提出。**KPI閾値・採点重みの変更は本キューで扱わない**(月次校正へ)
3. SLA: 登録から48時間。超過はAIが督促1回→日次報告の警告欄へ
4. 採用された提案の反映は該当正典の改版手続き(人間確定)で行い、AIは記帳のみを行う
5. 処理済みは週次で末尾「処理済み」節へ移動(削除しない)

## 項目書式

```
### [PB-Q-連番] 件名
- 機会: (機会ID・種別・対象工程)
- 種別: 改善提案 / Kill提案 / Archive提案
- 三点セット:
  - 事実: (実測データ+遡及リンク)
  - 選択肢: (採用 / 縮小採用 / 見送り)
  - 推奨と理由:
- 採点: __/50(軸別内訳) / 回収: __周
- 期待事業価値: (数値で1〜2行)
- 差分全文 / 収穫計画(Kill時):
- 確信度: __%(根拠1行)
- 登録日時 / 期限:
- 判定: (オーナー記入)
```
