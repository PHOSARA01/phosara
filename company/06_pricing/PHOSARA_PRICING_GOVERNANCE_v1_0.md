# 第1部 価格哲学(Pricing Philosophy)

1. **価値基準・時間非基準:** 価格は「灯した光の価値」——顧客の事業にもたらす成果——で決める。掛かった時間で決めない。時間で売る者は、速くなるほど貧しくなる。PHOSARAは資産ループで速くなり続ける会社であり、時間売りは自己否定である
2. **診断が先・価格もそれに従う:** 監査(L1)が全取引の起点である。監査なしの制作見積を原則出さない(例外はType 1)。監査が課題を確定するから、以後の価格は「見積もり合わせ」ではなく「処方」になる
3. **プレミアムポジション:** PHOSARAは4業界の中小事業者にとって「最も安い選択肢」ではなく「最も確かな一手」である。価格はその位置の表明であり、下げることは位置を捨てることである
4. **価格で競争しない(永久原則):** 相見積もりで価格を下げない。競争するのは診断の深さ・再現される品質・静かな美学であって、価格ではない。**断る勇気は価格表の一部である**(Principle 4.5継承)
5. **買いやすい最初の段:** プレミアムであることと、入りやすいことは両立する。L1監査は意図的に「最初の一歩として妥当な価格」に置き、以後は梯子で深まる
6. **誠実な価格:** 価格に含むもの・含まないものを先に言う。追加費用で回収するモデルを取らない(見積規則で範囲を統治する)

# 第2部 オファーラダー(Offer Ladder)

## 2.1 構造と依存関係

```
L0 無料相談(¥0・30–45分)……選別装置。売らない、診る
 │  適格(ICP)のみ通過 ▼
L1 事業監査 ……………………… 全ての起点。前払い。方向まで
 │  監査→次段 転換目標40% ▼
 ├─ L2 戦略(デザインコンサルティング)…… 解決策の設計
 │    │ ▼
 │    ├─ L3 ウェブサイト構築
 │    └─ L4 ブランディング構築
 │         │ ▼
 └────────┴─ L5 継続支援(月額MRR)…… 納品→継続 転換目標60%
               │ ▼
              L6 エンタープライズ / AI変革 …… 実績と信頼の到達点
```

## 2.2 段間の規則

| 規則 | 内容 |
|---|---|
| 依存 | L2以降はL1(監査)完了を前提とする。L3/L4の直接受注の例外はType 1+機会スコアリング35点以上 |
| 併走 | L3とL4は併走可能(WIP制限: 構築同時1件——併走時は1案件として契約・工程管理する) |
| 昇段(アップグレード) | 昇段の提案はPROPOSAL_BRIDGE経由のみ。**監査・制作の現場で口頭の売り込みをしない**(W9規律) |
| 降段 | 顧客はどの段からでも降りられる。降段はKillではなくN1育成へ(冷凍・廃棄しない) |
| 再入 | L5解約客・N1育成客の再入はL1(再監査)からを原則とする(事業状態は変わるため) |

# 第6部 収益規則(Revenue Rules)

1. **収益認識:** 入金主義(Company OS第4部・不変)。受注・請求は収益ではない。着手金は入金時に、残金は検収完了+入金時に認識する
2. **MRR:** 月額商品(L5各プラン・パチンコ月額・AI顧問・変革顧問)の合計。解約は通知期間満了の月末まで計上。週次計器盤でフロー収益と分離表示する
3. **単発収益(フロー):** L1〜L4・スポット・スプリント。フロー偏重は疲弊の兆候であり、**MRR比率30%到達を初年度の構造目標**とする(未達はKillではなくEX-12改善起案の対象)
4. **アップセル:** 経路はPROPOSAL_BRIDGEのみ。監査・制作の現場で売らない。転換KPI(相談→監査50%/監査→次段40%/納品→継続60%)を唯一の計測とする
5. **クロスセル:** 同一顧客への別ドメイン提案(例: サイト納品客へポートフォリオ)は、納品の儀式・定期レビュー(R2)でのみ行う。四半期1テーマまで(過剰販売の禁止)
6. **利益優先:** 粗利率70%を下回る構成の見積を原則作らない(外注・実費が嵩む案件は価格を上げるか受けない)。売上のための赤字受注を禁止する
7. **PBOS投資:** 入金の10%をPBOS投資枠へ(Company OS §4.6)。価格には資産化の工数(収穫・テンプレ化)が含まれている——収穫は無償のおまけではなく、価格に織り込まれた原価である

| 緊急価格 | **緊急値引きは存在しない。** 災害・障害等の緊急対応は特急料金(Q-5)の枠内で扱う。緊急時も価格の即断をしない(Company OS第11部・冷却期間の権利) |
| 既存顧客の改定 | 月額顧客への値上げは90日前の書面通知+次回更新から適用。通知なき遡及改定を禁止する |

# 第8部 将来拡張(Future Expansion)

## 8.1 新商品の価格化手続き(5段階)

1. **入口ゲート:** 最高判断ルール+機会スコアリング(35点以上で審査入り)
2. **位置決定:** オファーラダーL0–L6のどこに座るかを一意に定める(座れない商品はラダーの外=原則作らない)
3. **価値分析:** 顧客の得る成果・代替手段の価格・PHOSARAの原価(外注・ツール・工数)と粗利70%基準の検証
4. **三点価格の設定:** 初期/推奨/将来の3点+移行条件(事例数・成約率)を同時に定義する——1点だけの価格を作らない
5. **確定と登録:** Type 1で確定→本書へMINOR改版で登録→登録前の販売を禁止する

## 8.2 サンセット(販売終了)規則

- 2レビュー周期連続でKPI未達+再採点25点未満(Kill基準継承)で販売停止を審査
- 販売停止後も**既存契約は満了まで完全履行**(グランドファザリング)。月額商品は最長12ヶ月の移行期間内に後継プランへの移行を提案する
- 終了商品は本書から削除せず「販売終了」区分へ移す(価格履歴と整合性を保つ)

## 8.3 移行(マイグレーション)規則

- 商品改廃・価格改定時の既存顧客: 契約期間中は旧条件を完全保護。更新時に新条件(90日前通知)
- 後継商品への移行は、旧商品比で顧客の受け取る価値が下がらないことをStrategy Agentが答申で証明する
- 移行対応の工数はPBOS投資枠(§6-7)から支出し、顧客に転嫁しない
