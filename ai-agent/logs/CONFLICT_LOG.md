# CONFLICT_LOG — 例外・仕様矛盾ログ

**重要:** このファイルは追記のみ。削除・改変禁止。
仕様矛盾・自己レビュー不合格・未定義状況・低スコアが2回以上続いた場合に記録する。

**原則（Runtime §12.1）:**
未定義状況でコードや推測で回避してはいけない。
ここに記録し、オーナーへの相談エントリを作成する。

---

## エントリフォーマット

```markdown
---
## [CL-YYYYMMDD-NNN] [タイトル]

| 項目 | 内容 |
|---|---|
| 記録日時 | YYYY-MM-DD HH:MM JST |
| 対象ターゲット | [管理ID]（[会社名]）/ なし |
| 種別 | 自己レビュー失敗 / 低スコア継続 / 未定義状況 / 仕様矛盾 / その他 |
| 状況 | [何が起きたか — 原文で記述] |
| 対処 | [何をしたか] |
| オーナーへの相談 | 必要 / 不要 |
| 相談内容 | [必要な場合のみ: オーナーに判断を求める内容] |
| 解決済み | [ ] 未解決 / [x] 解決済み（YYYY-MM-DD） |
```
