# ブランディング監査テンプレート v1.0

*PHOSARA ブランディング監査テンプレート（実務用 診断フォーマット）*

本テンプレートは、クライアントのブランディング監査（ブランディング監査）を実施する際に、その場で記入して用いる実務フォーマットである。ブランディングガイドでも、ロゴデザインガイドでもない。判断基準は **PHOSARA_MASTER_CONTEXT_v1.0_JP.md** に、方法論は **Business_Audit_Guide_v1.0.md** に従い、デザイン監査の評価観点は **Design_Audit_Template_v1.0.md** と一貫する。

監査の目的は、**クライアントのブランドが、その価値・ポジショニング・アイデンティティを、あらゆる顧客接点で一貫して伝えられているかを評価すること** にある。ロゴや見た目の良し悪しではなく、ブランドの核が一言で言え、それが接点を越えて揺らがず再現されているかを問う。

主要4業界（建設・工務店／リフォーム会社／クリニック・整体／パチンコホール）に共通して使用できる。業界固有の論点は、各領域の「業界別の着眼点（参考）」として補助的に記載しているが、実際の記入は常にクライアントの回答・観察事実で行う。

### 監査の位置づけ（営業フロー上の位置）

```
事業監査（事業監査）          ── 何を解決すべきかを定義する
        ↓
デザイン監査（デザイン監査）         ── 資産が価値を伝えているかを評価する
        ↓
ブランディング監査（ブランディング監査）← 本書 ── 価値・立ち位置・人格が接点を越えて一貫しているかを評価する
        ↓
ソリューションガイド（解決策の設計）       ── どう解決するかを設計する
```

デザイン監査は「見え方」を評価する。

ブランディング監査は「ブランドそのもの」を評価する。

ブランディング監査は、デザイン監査の **下流** かつソリューション設計の **上流** に位置する。事業監査・デザイン監査が定めた優先課題（テーマ）を起点に評価し、その結論をブランディングブリーフとしてソリューション設計へ接続する。

## 記入の手引き

**記入の基本**
- 空欄はすべて記入欄である。診断設問・確認の観点・業界別の着眼点は、テンプレートに固定された参照情報であり、書き換えない。
- 事実と所見を区別して記入する。観察された事実はエビデンス欄に、解釈は所見・メモ欄に書く。
- 評価は「良い／悪い」ではなく、「ブランドの核が一言で言え、接点を越えて一貫して伝わっているか／いないか」を問う。

**三つの証拠源（エビデンス）**
- **観察** ── 既存の接点・制作物・発信を実際に確認した事実。
- **対話** ── ヒアリングで得られた、意思決定者・現場の言葉。
- **資料** ── 事業資料・ブランド規定・実績・市場情報。
- 一つの証拠源に頼らず、可能な限り複数を突き合わせて記入する。

**スコアリング・ガイダンス（重要）**
スコアは、各領域の「価値・立ち位置・人格がどの程度、明確化・可視化・一貫・再現されているか」を共通の尺度で表す。**スコアは、改善の優先順位を可視化するための指標であり、ブランドや企業の優劣を評価するものではない。** 低いスコアは「劣っている」ことを意味せず、「改善の余地と優先度が高い」ことを示す。

| スコア | 状態 | 改善の優先度 |
|---|---|---|
| 1 | 定義・可視化されていない | 最優先 |
| 2 | 部分的に定義・可視化されている | 高 |
| 3 | 一定程度定義・可視化されている | 中 |
| 4 | 概ね定義・可視化されている | 低 |
| 5 | 明確に定義され、一貫して再現できる | 現状維持 |
| — | 該当なし（対象外・未整備） | 別途記載 |

**評価の共通観点**
すべての領域は、最終的に次の四点に集約して読む。①本質（核が一言で言えるか）、②可視化（価値・立ち位置が見える状態か）、③一貫性（接点を越えて揃っているか）、④再現性（誰が運用しても同じブランド体験になるか）。
