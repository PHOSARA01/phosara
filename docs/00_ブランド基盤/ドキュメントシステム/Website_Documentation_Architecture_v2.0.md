# Website_Documentation_Architecture_v2.0

## 目的

Website関連ドキュメントを長期運用しやすい体系へ再編する。

## 現状レビュー

### ① 統合すべき資料

-   Website Design System

    -   Component Library
    -   UI System
    -   Animation System → **PHOSARA_Website_Design_System** に統合

-   Technical Specification

-   Development Guide → **PHOSARA_Website_Technical_Guide** に統合

-   Project Constitution

-   Content Operations Guide → **PHOSARA_Website_Operations_Guide**
    に統合

### ② 廃止すべき資料

統合後の以下は独立運用を終了する。 - Component Library - UI System -
Animation System - Development Guide - Project Constitution - Content
Operations Guide

### ③ 名前変更

-   Technical Specification → Website Technical Guide

### ④ 新しく必要な資料

新規資料は追加しない。

### ⑤ Documentation Systemへの反映

Website資料は以下の5冊を正式体系とする。

1.  PHOSARA_Website_Blueprint
2.  PHOSARA_Website_Copy
3.  PHOSARA_Website_Design_System
    -   UI
    -   Components
    -   Motion
4.  PHOSARA_Website_Technical_Guide
    -   Technical
    -   GitHub
    -   Claude Code
    -   Development
5.  PHOSARA_Website_Operations_Guide
    -   Constitution
    -   Content Operations
    -   Maintenance
    -   QA
    -   Versioning

## 運用原則

-   Blueprintを情報設計の唯一の基準とする。
-   Copyをコンテンツの唯一の基準とする。
-   Design SystemをUIの唯一の基準とする。
-   Technical Guideを実装の唯一の基準とする。
-   Operations Guideを運用の唯一の基準とする。

この5冊をWebsite Documentation Architecture v2.0の正式構成とする。
