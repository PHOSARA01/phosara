# PHOSARA_Website_Development_Guide_v1.0

## 01 開発方針

Blueprint・Copy・Design Systemを唯一の設計基準とし、一貫性を維持する。

## 02 開発フロー

要件確認 → UI設計 → 実装 → テスト → レビュー → リリース → 改善。

## 03 開発環境構築

Node.js・Git・エディタ・パッケージ管理を標準化する。

## 04 GitHub運用

main / develop / feature ブランチ戦略、Pull
Requestレビューを必須とする。

## 05 Claude Code運用

設計資料を参照し、実装前後で差分レビューを行う。

## 06 n8n連携方針

定型処理・通知・デプロイ補助など自動化対象を段階的に追加する。

## 07 品質管理

コードレビュー・Lint・Format・設計資料との整合性確認を実施する。

## 08 テスト方針

表示確認、レスポンシブ、アクセシビリティ、主要ブラウザを検証する。

## 09 リリース手順

最終確認後にタグ付けし、本番環境へデプロイする。

## 10 保守・運用

不具合修正、改善提案、依存関係更新を継続的に実施する。

## 11 更新ルール

Documentation Systemに従いバージョン管理し、変更履歴を残す。

## 12 将来拡張方針

AIエージェント、GitHub Actions、多言語対応、CMS連携を見据えて設計する。
