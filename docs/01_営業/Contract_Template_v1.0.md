# Contract_Template_v1.0

*PHOSARA 契約書（契約）公式テンプレート ― 実務用・記入式フォーマット*

---

## 本書について

本書は、PHOSARAの **契約書（契約）** を作成するための **記入式テンプレート** である。プレゼンテーション資料ではなく、案件の実務でそのまま記入し、双方で取り交わす。**承認された見積（見積）の後**に作成し、合意された範囲・金額・条件を、権利・責任・取消・機密保持を含む正式な契約として確定する。

本書は、次のいずれでもない。

- 提案書（提案）ではない。何を解決し、どう実現するかを示す文書ではない。
- 見積書（見積）ではない。費用・条件を見積として提示する文書ではない。
- 本書は、**正式な契約書**である。

契約書は、承認済み見積で合意した範囲・金額・条件を引き継ぎ、双方の権利と責任、知的財産、機密保持、契約の変更・解除を明文化する。提案と見積で「別途契約に定める」とした事項を、ここで確定する。契約の締結をもって、クリエイティブ制作へ進む。

### 唯一の基準

本書のすべての判断は **PHOSARA_MASTER_CONTEXT_v1.0_JP.md** に従う。理念・ミッション・ビジョン・ポジショニング・コアバリュー・ブランドボイス・サービスアーキテクチャ・役務範囲の規律は、本書では再定義せず、参照するのみとする。契約の前提となる範囲・テーマ・成果物・金額・条件は、承認済みの **Proposal_Template_v1.0** および **Estimate_Template_v1.0** に従う。

## 記入の手引き

**記入記号**

- `［　　　　　］` ── クライアント固有または案件固有の情報を記入する欄。空欄のまま取り交わさない。
- `〔A／B／C〕` ── 該当を一つ選択する欄。不要な選択肢は削除する。
- `□` ── 該当する項目にチェックする欄。
- 表内の空セルは、すべて記入欄である。

**記入の基本**

- **承認済み見積に従う。** 範囲・テーマ・成果物・金額・条件は、承認された見積から転記する。契約で新たな範囲を増やさない。
- **金額を創作しない。** 契約金額・単価・割合・税率は、承認済み見積の金額をそのまま反映する。根拠のない数値を契約に置かない。
- **クライアントデータを創作しない。** 当事者名・所在地・案件情報は、確定情報のみを記入する。
- **含む／含まないを明確に区切る。** 業務範囲は曖昧にしない。提供しない範囲（印刷・配送・施工・建設）を明示する。
- **固定記述は書き換えない。** 枠組みの説明・役務範囲の規律・本契約の位置づけは固定であり、編集しない。記入するのは記入欄のみである。
- **専門家の確認を経る。** 本書は契約の構成と論点を実務向けに整えた記入式テンプレートである。法的効力の確定には、締結前に弁護士等の有資格者による確認を行う。

**通貨・税の表記**

- 金額はすべて日本円（円）で記入する。
- 金額は、税抜（小計）・消費税・税込合計を分けて表記し、承認済み見積と一致させる。消費税率は記入時点の現行税率を記入する。

**当事者の呼称**

- 本契約では、業務を委託する側（クライアント）を「甲」、業務を受託する側（PHOSARA）を「乙」と表記する。各条文の「甲」「乙」は、02 契約当事者で定めた当事者を指す。

# 12 知的財産権

**成果物の権利の帰属**

**乙に留保される権利**

**著作者人格権**

*記入ガイド：権利譲渡の時点を明確にする（標準は支払完了時）。第三者素材の権利は譲渡対象に含まれない旨を明示する。実績公開の可否は、甲の意向を確認して記入する。*
